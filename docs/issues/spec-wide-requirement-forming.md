# spec-wide-requirement-forming

The stipulator adoption converted §13 (project invariants) to
REQ-formed requirements; §§1–12 still state their contracts as
narrative prose with no REQ ids. The corpus therefore compiles over
one section's requirement set, and a binding can only claim a §13
contract — a test witnessing, say, §9's sample floor or §10.1's
grouping rule has no id to bind against unless the obligation also
surfaces in a §13 requirement.

This is the two-places redundancy at a different altitude: where a
§§1–12 clause and a §13 requirement state the same obligation, the
requirement is the bindable form and the section prose the
authoritative elaboration — the split is deliberate and stable.
The collapse opportunity activates only when enforcement wants to
claim a contract that has no REQ-formed twin.
