# spec-wide-requirement-forming

Lands: Gofresh docs/plans/tooling-redesign.md 8.3.

The original premise that only §13 has requirement IDs is false for the
current corpus. Profile capture/publication/reporting and comparison
coverage/policies/dispositions, among others, already have IDs in their
subject sections. The remaining work is a census of genuinely unformed
obligations and duplicate requirement homes, not a blanket conversion of
§§1–12 or a second ID for every paragraph.

This is the two-places redundancy at a different altitude: where a
§§1–12 clause and a §13 requirement state the same obligation, the
requirement is the bindable form and the section prose the
authoritative elaboration — the split is deliberate and stable.
The collapse opportunity activates when enforcement needs a contract with
no REQ-formed home, or two homes duplicate the same obligation. Re-census
the previously named pairs — `REQ-pew-recording-recovery` beside §5 and
`REQ-pew-status-completeness` beside §12 — against their current text and
bindings before choosing a home. Preserve distinct obligations, normative
strength and enforcement claims; move citations and bindings with any actual
consolidation. Retained charter 232 supplies this inventory; active item 8.3
owns its reconciliation with current defaults, guidance and exits.
